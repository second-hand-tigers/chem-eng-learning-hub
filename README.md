# chem-eng-learning-hub

Welcome to the central learning hub for chemical engineering project development. This repository provides orientation, guidance, and structured resources for the full lifecycle of capstone-style engineering projects.

## Project Directory
Explore all example projects here:  
**[chem-eng-projects](https://github.com/second-hand-tigers/chem-eng-projects)**

## Purpose
This hub supports the complete workflow of chemical engineering design projects, including:

- Project ideation and concept generation  
- Screening and selection of viable design options  
- Flowsheet development and modeling  
- Model validation and sensitivity analysis  
- Economic evaluation and optimization  
- Post-project sustainment and applied use-case development
